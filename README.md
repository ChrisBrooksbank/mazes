# Mazes

Generate, solve, and walk through mazes in 2D, isometric, and 3D views.

## Features

- **Maze generation** — Multiple algorithms (recursive backtracker, Prim's, Kruskal's, etc.)
- **2D view** — Classic top-down maze view
- **Isometric view** — Stylized angled projection
- **3D walkthrough** — First-person perspective navigation
- **Maze solver** — Visualize solving algorithms (BFS, DFS, A*)
- **PWA** — Installable, works offline

## Tech Stack

- Vite + TypeScript
- Three.js (3D and isometric rendering)
- Vitest + Playwright

## Development

```bash
npm install
npm run dev        # Start dev server
npm run build      # Production build
npm run check      # Lint, typecheck, test, format
```
